## 📱 Sobre el proyecto

Swipe Pics es una aplicación Android desarrollada con Flutter que transforma la limpieza de fotos en una experiencia inspirada en apps de swipe tipo Tinder.

La idea nació de un problema real: tener decenas de miles de fotos acumuladas y que ordenar o borrar imágenes fuese una tarea lenta y aburrida.

La app permite revisar fotos una a una mediante gestos intuitivos y animaciones fluidas, haciendo el proceso mucho más rápido y satisfactorio.

---

## ✨ Features

- 👈 Swipe izquierda → mover a papelera
- 👉 Swipe derecha → conservar foto
- 🗑️ Papelera temporal con restauración
- ⚠️ Confirmación antes del borrado definitivo
- 🔀 Modo aleatorio real
- 📅 Orden por fecha (recientes / antiguas)
- 📊 Estadísticas de limpieza
- ⚡ Animaciones fluidas y minimalistas
- 🌙 Diseño oscuro moderno
- 📂 Gestión real de galería Android
- 📱 Optimizada para grandes galerías (+38k fotos probadas)
